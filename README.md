# Stemmenstudio

Kies een video (YouTube, Vimeo, directe videolink of eigen upload), kies een clip van 1:00, 1:30 of 2:00, bekijk hem en spreek er je eigen voice-over overheen. Met spelers, opdrachten, punten en bewaarde clips.

Alles zit in `index.html`. Zet GitHub Pages aan (Settings > Pages > branch `main`, map `/ (root)`) en open de link. YouTube en Vimeo werken alleen via een https-adres.
